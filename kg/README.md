# Knowledge Graph Assets

- `ontologies/`: OWL/RDFS models.
- `shapes/`: SHACL validation constraints.
- `examples/`: Sample RDF payloads for tests and demos.

## Included Modules

- `ontologies/semanticops-core.ttl`: platform-level knowledge asset and business entity vocabulary.
- `ontologies/semanticops-medical.ttl`: local medical dataset vocabulary for cohorts, patient profiles, observations, care plans, diagnoses, and UCI Heart Disease features.
- `shapes/semanticops-core.shacl.ttl`: base validation for knowledge assets.
- `shapes/semanticops-medical.shacl.ttl`: medical dataset validation constraints.
