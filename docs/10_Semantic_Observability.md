# Semantic Observability

Semantic observability tracks graph quality, ontology drift, validation stability, workflow outcomes, and agent behavior. Observability events should be stored separately from RDF graph content while linking back to named graphs and workflow runs.

Initial metrics:

- SHACL conformance rate.
- Ingestion failure rate.
- Triple volume by named graph.
- Ontology change frequency.
- Agent retry and escalation counts.
