# Technology Stack

- Next.js and TypeScript for the enterprise web interface.
- FastAPI and Pydantic for API delivery and contract validation.
- LangGraph for deterministic multi-agent workflow orchestration.
- RDFLib for RDF parsing, serialization, and graph manipulation.
- Apache Jena Fuseki for SPARQL graph storage.
- pySHACL for SHACL validation.
- OWLReady2 for ontology loading and reasoning integrations.
- PostgreSQL for operational data.
- Docker Compose for local development and service composition.
